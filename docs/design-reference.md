# 车型展厅页面参考

2026-10-21，根据“同类网站借鉴、减少模板感”的要求实地浏览以下官网页面。

- [地上铁轻卡车型库](https://www.dstcar.com/index.php/portal/list/index.html?id=11)：分类入口清楚，车辆照片、车型名称和详情入口构成主体。
- [地上铁远程 H8E 详情](https://www.dstcar.com/index.php/portal/article/index.html?id=531&cid=11)：以车辆图片、核心参数及租购咨询作为详情重点。
- [国慧绿源](https://www.guohcar.com/)：新能源物流车租售公司官网，导航有车型库、业务服务和用车咨询。

这版采用更直接的经销商展厅结构：公司信息与咨询入口、真实车场照片、温控与车身筛选、车型目录、租售说明。去掉大段营销口号、英文装饰、悬浮徽章和装饰性网格背景。车型卡片保留实际图片、名称、参数、现车状态及咨询操作。

首页照片继续使用用户提供的 Word 资料，画面中有“杭州好滴哥店”店招。没有复制同行的标志、图片、宣传承诺或代码。照片取自 `江淮蓝猫客运版七方车.docx`，对应已发布素材 `/vehicles/vehicle-19/image2.webp`；该车型下架时首页会选择其他已上架车型。

公司图标已与业务数据分离，管理员可在“网站设置”上传、更换或移除，保存后前台读取持久化设置。未设置图标时使用“好”字占位。
