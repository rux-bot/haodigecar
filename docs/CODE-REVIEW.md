## 确认并修复的问题

| 优先级 | 问题与影响 | 修复与验证 |
| --- | --- | --- |
| P1 | Windows 大小写不敏感，数据库以 URL 原文判断归属。更改图片文件名大小写可绕过另一会话的草稿归属检查；原会话清理时会删除另一记录已引用的同一文件。 | server/media.mjs 的 resolve 逐级核对实际文件名大小写；合法大写文件仍可使用。隔离测试覆盖跨会话、别名拒绝、共享引用及最后引用清理。 |
| P2 | 静态回退使用未解码路径判断命名空间，编码地址可能绕过专用媒体路由，读取旧 dist 中已删除图片的副本。 | server/app.mjs 在媒体和通用静态中间件之前解码、规范路径并拒绝别名。编码斜杠、编码命名空间、反斜杠及大小写入口均返回 404。 |
| P2 | 登录失败限流只绑定 IP 与账号组合，更换账号名可持续触发同步密码哈希并增加限流记录。 | 增加同一连接 IP 每 15 分钟合计 30 次失败限制；原组合 10 次限制保留。持久化计数，重启、成功登录及伪造 X-Forwarded-For 不会清掉计数。 |
| P2 | 已标记丢弃但暂因文件占用未删掉的草稿，可以被旧客户端重新保存，撤销清理队列。 | validate 拒绝 discarded=1 的图片并返回 409；EACCES 故障注入验证队列继续保留、后续重试可清理。 |

## 交互改进

- 顶部导航随点击、温控筛选和手动滚动同步；咨询弹窗及页尾联系区对应联系我们，手机也显示选中横线。
- 筛选增加已选条件标签、单项移除、清空全部和结果/已显示数量。手机保留温控及搜索，把车身和品牌收进“更多筛选”；底部筛选入口会展开全部条件。
- 键盘移除条件后保持焦点可追踪；添加清晰焦点轮廓及减少动画偏好支持。异常详情 URL 安全解析，非法筛选条件可看到并清除。
- 后台未编辑可直接关闭；有修改时提供“继续编辑 / 放弃修改”。设置未保存时阻止直接退出或返回前台，刷新前提示；隐藏上传草稿也纳入保护。
- 上传展示进度，前端在上传前校验最多 30 张。手机后台导航改为图标配短标签，避免文字逐字竖排。
- 后台新增账号安全入口；新密码 12–128 字符，含文字和数字；改密成功要求所有设备重新登录。实际密码由管理员自行输入。
